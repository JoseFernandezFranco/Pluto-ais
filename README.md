# Pluto-AIS

RSSI por trama de AIS recibido con un ADALM-Pluto (UPCT). Datos y dashboard generados automáticamente por `plutoais.publish`; no editar a mano.

- Dashboard: GitHub Pages de este repositorio.
- Datos: `data/<campaña>/` (CSV comprimidos por segmento de 1 h, potencias en dBFS, tiempos en UTC).
